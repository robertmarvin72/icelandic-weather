**P5 — Niðurstaða `geometry_only`/`same_place`.** (a) Birta: `frá → til`, valinn valkostur (P6) og `via` (strengir úr API, sem sérnöfn; `via` vantar á hringpilot-svörum án valkosta og er í `options[].via` — viðmótið verður að þola vöntun).
