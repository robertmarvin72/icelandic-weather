This is the key thing to review: is this an honest, usable MVP approach, or does it look misleading without the gap note?
  2. The reused connector (orange) -- same ~4.39 m estimated bridge already approved in the Patreksfjörður round, reused byte-identical here.
  3. The route itself -- does the blue line follow Miklidalur with no detour via the Hálfdán/Bíldudalur branch (grey)?
  4. The branch points (grey) -- shown only as advisory "possible future connection" markers, never composed into this route.

Takmörk / Limits

  • This is tier 0 geometry (the finest precision tier), offline-reprojected from the owner-provided WGS84 source.
  • The route does not reach Tálknafjörður itself. It ends at the retained vegur 617 (Tálknafjarðarvegur) geometry's own literal end -- documented in its own source description as ending "að 1sta ljósastaur" (at the first streetlight). Town continuation into Tálknafjörður is not included in this MVP.
  • The ~995 m gap to the owner's own Tálknafjörður coordinate is a planar straight-line distance, never a driving distance, and is never counted in lengthM. No road line or straight line is drawn to the owner point, to avoid implying a connection that does not exist in the retained data.
  • The Patreksfjörður endpoint and the estimated connector are reused byte-identical from the already-approved Flókalundur<->Patreksfjörður round.
