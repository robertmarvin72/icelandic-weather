Map approval here confirms this round's own 10 new cross-leg Westfjords pairs -- it must NOT be read as confirmation of winter closure, driving conditions, or current access for any of them.

Pair (select to switch)

Litir / Colors

  • The selected real route, tier 0 (both directions are available in the selector)
  • Estimated connector(s) actually present on this pair (-4 ~5mm Búðardalur↔Flókalundur, and/or -5 ~4.39m Patreksfjörður approach)
  • Route endpoints (both ends of the selected pair)
  • Owner coordinates for all six supported places (not necessarily reached by every route -- Tálknafjörður's own owner point is never reached)

Primary review cases (Jonesy)

  1. Búðardalur ↔ Hólmavík -- reuses the known Þröskuldar chain
  2. Flókalundur ↔ Tálknafjörður -- shortest new pair, no connector used at all
  3. Hólmavík ↔ Patreksfjörður -- uses BOTH estimated connectors (-4 and -5)
  4. Ísafjörður ↔ Patreksfjörður -- passes through the 3834 roundabout

Takmörk / Limits

  • All 10 pairs are tier 0 geometry, composed on the merged server_data/westfjords-region-combined.json (a byte-identical sourceId merge of the eight already-approved Westfjords region files -- no new acquisition, no new transform).
  • Tálknafjörður's own endpoint never reaches its owner coordinate (~995 m short, town continuation not included) -- same gap already approved in the westfjords-talknafjordur-mvp round, reused byte-identical here.
  • Estimated connector lengths (~5 mm and/or ~4.39 m) are surfaced separately in estimatedConnectorLengthM, never silently folded into the visible route without a popup label.
  • Tile basemap loads live from OpenStreetMap when opened via http://127.0.0.1:8778/ -- no Vegagerðin network call is made by or for this page.
