- **RJ4 (alvarleiki: lágur–miðlungs; AC-2 viðmið og mörk):** viðmiðið „`0 <= delta < 3 s` PASS“ skilgreinir ekki neikvætt delta (mælihávaði; hraðar eftir en fyrir) og `UNKNOWN`/`FAIL`-mörk á mælingarfjölda sem passar í `≤4` CLI-turna. Skilyrði: forskrá nákvæma mæliaðferð og regla sem rúmast í budgetinu — t.d. 2 baseline-turnar fyrir `apply` og 2 mælingar eftir `apply` (sem eru jafnframt AC-3 áhorfið), `delta` = hærri eftir-mæling mínus hærri baseline-mæling, `delta < 3 s` (neikvætt leyft) = `PASS`-tími, `delta ≥ 3 s` í *einhverri* eftir-mælingu = `FAIL`/rollback, ófullnægjandi eða ósamræmdar mælingar (t.d. baseline-munur sjálfur ≥1,5 s) = `UNKNOWN`; skýra að tíma-`PASS` er ekki AC-3 `PASS`; og að ef ≤6 tilkynninga mörkum verður náð (með `idle_prompt`) hættir eigandi — að fara yfir er ekki „bilun“ heldur brot á heimildinni. Ekki bæta við auka mælingaturnum án nýrrar heimildar.
- **RJ5 (alvarleiki: lágur–miðlungs; rollback-innihald og backup-flutningur):** `rollback` endurheimtir *alla* skrána í ástand fyrir `apply`; ef Claude Code sjálft hefur skrifað í `settings.local.json` eftir `apply` (t.d. leyfi sem eigandi samþykkti í prófi — docs segja að Claude Code vistar stillingar í þessa skrá) tapast það. Skilyrði: runbook krefst tool-lausra turna (til samræmis við WV6(c)) og banns við „Always allow“ í prófunum; skrefið *fyrir* rollback keyrir texta-hash blokk (RJ1) til að sýna hvort skráin sé enn jöfn heimilaða `after_preview_sha256` — ef ekki, skrá það og velja afrit vísvitandi (rollback er áfram heimill samkvæmt heimildinni, en eigandi veit hvað tapast). Ef tól-backup er flutt út úr repo skal sú breyting vera *eitt* skref sem uppfærir bæði flutninginn og staðbundnu backup-breytuna, og blokk staðfestir að flutta afritið sé enn gilt JSON og jafnt (texta-hash) því sem `apply` bjó til, áður en rollback er heimill; hand-afritið er **ekki** það sem `rollback` notar.
- **RJ6 (alvarleiki: lágur; staðfesting og skil):** viðtaka drögin krefjast tempfile-staðfestingar á Windows; skýrslan skal að auki sýna: (a) blokkirnar keyrðar *orðrétt* eins og þær standa í runbook (afrit úr skjalinu, ekki endurskrifaðar) í 5.1; (b) config-tilfelli þar sem `DEV_NOTIFY_CONFIG_PATH` er sett en skráin **vantar** (á að gefa `STOP`, ekki „sjálfgefin gildi í lagi“) og tilfelli með skrá sem ekki er hægt að lesa; (c) canary-leit í *öllu* úttaki (stdout og stderr) og í `git status`; (d) hver tala merkt CC-attributed (Windows/Python-útgáfa) vs. Jonesy-Linux; (e) að `RH1`–`RH3` standa og að diagnostic er ekki keyrt; (f) að engin raun-config var lesin — fixtures eingöngu. Útkoma `PREPARED_AWAITING_OWNER_ACTIVATION` ef allt er hreint; ekkert E2E PASS og engin eigandaundirskrift frá CC.
