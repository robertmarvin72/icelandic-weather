## 2. C3 — Direction-evidence rule (written before any scoped chain piece was individually examined for direction)

Graded per section type, applied uniformly to whatever the C2 offline inventory finds:

| Section type (VEGHLUTI) | What counts as VERIFIED | What stays INFERRED | What stays UNKNOWN |
|---|---|---|---|
| **1 — undocumented role** (per #483 `research-report.md` line 42: only 0/3/4/5/6/7 are officially documented; 1 and 8 are not) | Topological adjacency between two tier0 pieces: ONLY an exact (0.00 m) shared native-ISN93 endpoint coordinate, OR a measured gap that is itself independently corroborated by something other than proximity alone (e.g. continuous `KAFLANR` lettering/numbering across the gap, or a shared `STADARLYSING`/name continuation) — proximity alone, however small, is never on its own promoted to VERIFIED. No inherited 30/50 m threshold from #483/#491 is reused here as an automatic rule. | That VEGHLUTI "1" means a single, undivided, ordinarily-bidirectional carriageway — this is #483's own inference, not an official definition, so it stays INFERRED here too, applied consistently. If no VEGHLUTI 6/7 paired divided-carriageway exists for a given stretch, the SAME single verified line is used for both direction conventions (not two independently-verified geometries) — this itself is disclosed as INFERRED bidirectionality by ordinary-road inference, not an authority confirming legality of travel in both directions. | Whether a specific piece carries any undocumented one-way restriction (signage, seasonal closure to one direction, etc.) — no retained source speaks to this either way. |
| **5 — hringtorg/roundabout** | A `VEGHLUTI=5` feature whose own coordinates sit at/near a chain boundary is a real, mapped feature (VERIFIED existence), bridged by its own recorded native gap exactly as #491 did for the Borgarnes roundabout (30401) — never computed as an arc length. | Which exact point of a roundabout a route "enters/exits" at (a roundabout permits multiple paths through it). | — |
| **6/7 — paired divided carriageway ("í og á móti ferðarátt")** | That a 6-role and a 7-role piece sharing the same `KAFLANR`/area are a genuine opposite-direction PAIR (VERIFIED if both exist for the same stretch). | Which of the pair is the "real-world" northbound vs. southbound one — a geometric bearing can be computed independently (not reused from the unrelated Rauðavatn–Borgarnes chain's own convention, which is a different location), but a computed bearing is still INFERRED, not an official direction record. | Whether traffic is legally permitted in the inferred direction — requires an authority/signage source not in retained data. |
| **3/4 — aðrein in/out, ramps** | Existence/connection point only (bridging, not a route segment in its own right) — same treatment as #491's ramps. | — | Whether a ramp changes the route's own direction-of-record at that point. |
| **8 — undocumented role** | Nothing promoted above UNKNOWN for direction purposes without separately found documentation. | — | Everything about this role's meaning and direction implication. |
| **Tunnel (any VEGHLUTI, e.g. Hvalfjarðargöng-style)** | Existence/entry-exit bridging only. | — | Direction inside the tunnel, unless a named one-way exclusion (like 814700037/2982 in the Rauðavatn–Borgarnes chain) is found in retained data for this specific tunnel. |

**List-reversal rule (binding, per item 3):** reversing the printed order of a chain, or reading a piece's own `VEGHLUTI` number, is NEVER by itself evidence of the opposite legal driving direction. A single VEGHLUTI=1 undivided line, once VERIFIED as a continuous chain, is the SAME geometry regardless of which end you start counting from — so (per the INFERRED-bidirectional-ordinary-road grading above) it is graded identically for both direction conventions, not asymmetrically "more verified" one way than the other. Where a genuine 6/7 divided pair is found, the two directions are graded separately and a reversal of ONE piece's digitized order is still not proof of the other's real-world direction.

**Pre-registration commitment:** this rule is written before any scoped (Borgarnes–Akureyri) chain piece has been individually graded (the C2 offline inventory below was run immediately after this rule was written, in the same sitting, and no piece's own grade was allowed to change this rule after the fact — see §5 "no post-hoc rule changes" for the one actual case this came up in, disclosed not hidden).
